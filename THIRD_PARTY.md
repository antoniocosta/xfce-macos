# Third-party software

Nothing below is copied into this repository. The installers download or build each
project from its own source at install time, under its own licence.

| Project | Used for | Licence | How |
|---|---|---|---|
| [Toshy](https://github.com/RedBearAK/toshy) | Cmd-key shortcuts | GPL-3.0 | its own installer; the white tray icon is drawn at install time from Toshy's icon |
| [WhiteSur GTK theme](https://github.com/vinceliuice/WhiteSur-gtk-theme) | window theme, dock theme | MIT | its own installer |
| [WhiteSur icon theme](https://github.com/vinceliuice/WhiteSur-icon-theme) | the horizontal battery icons only | GPL-3.0 | its installer, run into a temporary folder; the battery icons are kept |
| [apple_cursor](https://github.com/ful1e5/apple_cursor) | macOS cursors | GPL-3.0 | release download |
| [picom](https://github.com/yshui/picom) | the desktop slide | MPL-2.0 / MIT | built from a release tag |
| [Plank Reloaded](https://github.com/zquestz/plank-reloaded) | the dock | GPL-3.0 | its apt repository |
| [Touchégg](https://github.com/JoseExposito/touchegg), rofi, xfce4-appmenu-plugin, Inter | gestures, Spotlight/Launchpad, global menu, font | various | Ubuntu/Mint packages |

net-badge's idea and colour tiers follow [macos-network-badge](https://github.com/Someniak/macos-network-badge).
